# Submission conventions

- Write concise English comments, docstrings, and notebook explanations.
- Preserve task instructions and recorded experimental data verbatim.
- Keep perturbations at the environment level so all baselines receive the same protocol.
- Preserve native baseline memory selection and action generation when integrating RI-Mem.
- Prioritize baseline coverage and the requested RI-Mem integrations. Do not add ablation experiments unless requested.
- Distinguish implemented interfaces, integration checks, and measured benchmark results.
